# One phrase for unplotted rows: 'not on the radar'

From the PR 06 plan review. mockup.html's table flag reads 'not plotted'; FR-17's warning and model::Catalogue::accessible_name say 'not on the radar'. If the flag is visible inside the control, WCAG 2.5.3 wants the same words. Use 'not on the radar' in the mockup and PR 14's table.
