# Tagged PDF: Layout BBox on Figure and Table

From the 21c-2 review (a11y 4): ISO 32000-1 Table 344 makes the Layout BBox required for illustrations and tables in content; veraPDF UA-1 does not check it, PDF/UA-2 requires it, Acrobat focus highlight and reflow use it. Write a Layout attribute with the radar group bounds and each table page bounds.
