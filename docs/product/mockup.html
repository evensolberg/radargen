Not the real tool — a static preview validating: an arbitrary (non-4) number of quadrants, radar + legend as one SVG document (PRD §6.2a), keyboard/hover interaction (§6.2b), and a single layout that scales from desktop to phone width with no side-by-side/stacked breakpoint to maintain. Quadrants render in case-insensitive alphabetical order (§9); rings are fixed here at this practice's default — Retire → Adopt → Trial → Assess, center to edge — since validating arbitrary --rings configurability doesn't need a second rendering path, only a different band count, already proven by the quadrant case.
