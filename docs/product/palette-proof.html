An eight-colour quadrant palette, verified against both themes

FR-67 cycles one palette entry per quadrant. All eight clear WCAG 1.4.11's 3:1 non-text contrast on every surface in both built-in themes. Because FR-67 assigns by index, palette order is usage frequency — so quality is front-loaded and every prefix is itself a good palette.

Under colour-vision deficiency

Simulated with the Viénot–Brettel–Mollon model. The figure is the smallest pairwise Lab distance in the set — how close the two most similar colours get for that viewer. The obvious palette (blue / vermillion / green / purple / gold) collapses here: vermillion and gold land at ΔE 3.9 under deuteranopia, effectively one colour. Olive replaces gold for that reason. The floor for all eight is set by olive against green under deuteranopia — the price of the sixth entry.

None of this is load-bearing. FR-39 already guarantees quadrant identity never depends on colour — angular position and the sector label always disambiguate, which is also what lets FR-67 cycle the palette past five quadrants. Separability here is a courtesy to the reader, not a correctness requirement.

Why it stops at eight

Requiring one colour set to clear 3:1 on both themes confines every entry to relative luminance 0.12–0.30. Inside that band there are only so many hues a dichromat can separate, because protanopes and deuteranopes have roughly one usable hue axis rather than two. The degradation is measured, not assumed:

Two alternatives were measured and rejected. Per-theme series values — a separate hex for light and dark — widens the band and reaches ΔE 33.6 to normal vision, but re-admits the violets and browns that collide with vermillion and olive, collapsing the CVD floor to 3.5. Optimising purely for the CVD floor reaches 13.5, but produces three browns and two magentas: robust to measure, poor to look at.

The palette as CSS

This doubles as the sample --palette file §6.6 promises to ship. Note the shape: a custom palette is exactly one set of colours, not a light/dark pair — which is why it is mutually exclusive with --theme (FR-59) and why supplying it removes the theme toggle from an HTML build.

/* radargen — built-in palette. Series values are shared by both themes. */
:root {
  /* Quadrant series — FR-67 assigns by sorted quadrant index, cycling.
     Order is usage frequency: a 3-quadrant radar uses only 1..3. */
  --series-1: #0072B2;  /* blue       */
  --series-2: #C25400;  /* vermillion */
  --series-3: #00857A;  /* teal       */
  --series-4: #787832;  /* olive      */
  --series-5: #B5476B;  /* rose       */
  --series-6: #2F9626;  /* green      */
  --series-7: #C431B8;  /* magenta    */
  --series-8: #9D5A43;  /* terracotta */

  /* Light theme */
  --surface-1: #FFFFFF;
  --surface-2: #F4F5F7;
  --text-primary: #16191F;
  --text-muted: #585F6B;
  --stroke-ring: #7E858F;
  --stroke-divider: #848B96;
  --marker-hollow: #FFFFFF;   /* FR-20 conditional fill = the surface */
  --focus: #0B5FA5;
}

/* Dark theme. Series values are unchanged; only neutrals move. */
:root[data-theme="dark"] {
  --surface-1: #15181D;
  --surface-2: #1E222A;
  --text-primary: #E8EAEE;
  --text-muted: #A6AEBB;
  --stroke-ring: #6C7480;
  --stroke-divider: #666E7A;
  --marker-hollow: #15181D;
  --focus: #7FB8E6;
}

Contrast ratios computed per WCAG 2.1 relative luminance; dichromacy simulated with Viénot–Brettel–Mollon in linear sRGB and compared in CIE Lab. Every figure on this page is computed, not estimated. The one judgement call left open is aesthetic: olive is the least conventional of the eight, and it is there because it survives deuteranopia where gold does not.
